# 2026-10-08, after midnight: the page (M2)

## What was built

`site/`, built into `docs/` by `site/build.mjs`:
- a full-size console in the middle, labelled "MicroPython 1.26 in WebAssembly" and "Could run on a
  Raspberry Pi Pico 2 W or an ESP32", with its stats (files, lines, heap, fingerprint) and a serial log;
- the steps: passkey, first key, shielded Safe, fund it, press;
- beside it: the Safe, the key ladder with what an attacker sees and needs, the history;
- below: the attack room, the danger case, how it works, and "Check this page".

No framework. viem for the chain, bundled by esbuild and not minified (708 KB), so it can be read. No
service worker: the page has no worker for a header to bind, so a `<meta>` CSP carries the policy, and
the page refuses to run in a frame in place of `frame-ancestors`.

## The e2e test, and what it found

`site/e2e.mjs`: Chromium, a virtual passkey with PRF, a test wallet backed by Anvil, and a local chain
with Base Sepolia's bytecode. The first run got as far as the build, then failed. In order:

1. **The test's fault:** it waited for "Fund it", which the steps bar shows on every screen, so it moved
   on before the build happened. It now reads the screen without the steps bar.
2. **The test's fault again:** its first fix used `eval` inside the page, which the page's CSP refuses.
3. **A real bug: the Safe transactions didn't run.** Both presses burned their keys, but the Safe's
   nonce stayed at 0. A wallet's gas estimate is the least gas with which nothing reverts; with the
   Safe transaction allowed to fail, that is gas with which it fails. The page now estimates as if
   every part must succeed, and passes the gas to the wallet.
4. **A real bug:** after a reload the page didn't reconnect the wallet, so "send approval 2 again" had no
   button. It now reconnects, without a prompt, the wallet it used last.
5. **The test's fault:** it checked the red page before the screen redrew.
6. **A flaky check:** the danger case sometimes found no forgery in two million tries; four random
   signatures can leave long odds. It now signs until the odds are about 1 in 50,000.

Then it passed twice in a row: 36 checks. (The wallet chooser later added two: 38.)
