# 2026-10-08, about 00:15: publishing, and the site going live

## A private history

The checkout's remote was still `jmcpheron/pico-quorum`, which turned out to be **private**. The branch
carried its whole history: photos, board designs, every past commit. Pushing it to the public
`jmcpheron/sign-and-burn` would have published all of that.

Asked; the answer was a **fresh history**. One root commit with the Sign and Burn tree went to
`jmcpheron/sign-and-burn` as `main`. Locally:
- `origin` is now sign-and-burn; the old remote is `pico-quorum`;
- `public-main` tracks `origin/main`, and is where work goes;
- the old branch still holds the private history, and is never pushed.

CI passed on GitHub on the first push: console, contracts and site, including the rebuild check on
Linux and the Chromium e2e.

## The domain

DNS, set at the provider: the four GitHub Pages `A` records on the apex, and `www` as a `CNAME` to
`jmcpheron.github.io`. No `AAAA` records yet; IPv6-only visitors can't reach it. The domain was
verified at GitHub.

Pages was turned on with the API: deploy from `main`, folder `/docs`, custom domain `signandburn.app`.
The certificate was approved at once, for `signandburn.app` and `www.signandburn.app` (expires
2027-01-05), and HTTPS enforced. `http://` redirects to `https://`, and `www` to the apex.

## Checking what Pages serves

Every file in `SHA256SUMS`, fetched from the live site: 17 of 18 matched. The 18th, `CNAME`, was
missing. Pages reads it for the domain and doesn't serve it, so a visitor's `sha256sum -c` would have
failed. `CNAME` is now left out of `SHA256SUMS` and `BUILD.json`. After the fix: 17 of 17.

Content types: `.wasm` as `application/wasm`, the modules as JavaScript, the console's `.py` files as
`application/octet-stream`, which `fetch` reads fine.

## A smoke test of the live page

Headless Chromium with a throwaway virtual passkey, up to the build screen, sending nothing. The console
booted with fingerprint `a46b5cfd…`, the README's. Safe's passkey factory on Base Sepolia named the same
signer address the console worked out. The seat and Safe addresses were worked out against the real
chain. No CSP violations, no page errors.
